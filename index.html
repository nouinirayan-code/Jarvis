L'Art de la Guerre

Jeu de stratégie en temps réel — commandez votre armée et détruisez la base ennemie.

Difficulté

Comment jouer

Objectif : détruire tous les bâtiments ennemis (en rouge) avant qu'il ne détruise les vôtres.

  • Clic gauche : sélectionner (glisser pour une sélection en rectangle, Maj pour ajouter, double-clic pour tous les types identiques).
  • Clic droit : ordre contextuel — déplacer, attaquer, récolter une mine d'or, construire, point de ralliement.
  • A + clic : attaque-mouvement (les unités attaquent tout ce qu'elles croisent).
  • S stop, H tenir la position, B menu de construction (ouvriers).
  • Ctrl+1-9 : créer un groupe, 1-9 : le rappeler (deux fois pour centrer la caméra).
  • Flèches / bord de l'écran / clic molette : déplacer la caméra. Molette : zoom. Espace : centrer.
  • . : ouvrier inactif, P : pause, Échap : annuler.

Unités : les lanciers battent la cavalerie, les archers battent les lanciers, les chevaliers battent archers et catapultes. Les catapultes rasent les bâtiments.

Économie : les ouvriers récoltent l'or et le rapportent au Quartier Général. Construisez des maisons pour augmenter la population.

Pause

Victoire !
